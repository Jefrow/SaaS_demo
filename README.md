# Front — SaaS Landing Page Demo

A fully responsive SaaS marketing landing page built with vanilla HTML, CSS, and JavaScript. Designed to demonstrate a polished, production-quality front-end without any frameworks or build tools.  
[See project demo here](https://saa-s-demo.vercel.app/)

## Features

- Sticky navigation bar with scroll detection
- Responsive hamburger menu for mobile viewports
- Sections: Hero, Key Benefits, CTA, Why Front, Video Demo, Testimonials, Pricing, Hire Us, Footer
- Slide-in demo/docs panel in the top bar
- Contact form with budget selector and country dropdown
- Integrations showcase (Google, PayPal, Atlassian, Asana, and more)
- Trusted-by logos (Weebly, Uber, Slack, Airbnb, Spotify)
- Poppins typeface via Google Fonts, icons via Font Awesome
